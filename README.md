# holbertonschool-web_front_end

This repository contains front-end exercises and small projects completed for the Holberton School web front-end curriculum. It is intended to collect learning materials, practice assignments, and example implementations that demonstrate core front-end skills such as HTML, CSS, responsive design, accessibility, and basic JavaScript.

## What you'll find here

- Module-based exercises and mini-projects covering:
  - HTML structure, semantics, and forms
  - CSS layout, selectors, responsive design (flexbox, grid), and transitions
  - Basic JavaScript for DOM manipulation, events, and simple UI logic
  - Accessibility and progressive enhancement
- Example assets (images, icons) and starter templates to preview work in a browser.
- README or instruction files in subdirectories explaining individual exercises where applicable.

## Repository layout (example)

Each module or exercise is organized into its own directory. A typical structure looks like:

- 0x00-html/
- 0x01-css/
- 0x02-javascript/
- projects/
- assets/

Note: exact folder names may vary — browse the repo to see the full structure and open individual exercise folders for details.

## How to preview

The simplest way to view any exercise is to open its `index.html` file in a web browser. For a local HTTP server (recommended for features that require a server):

- Python 3: `python -m http.server 8000`
- Node (http-server): `npx http-server .` or install with `npm i -g http-server`

Then open `http://localhost:8000/` and navigate to the exercise folder.

## Requirements

- Modern web browser (Chrome, Firefox, Edge, Safari)
- For some projects: Node.js and npm (only when build tools or packages are required)
